
# ResNet50 Food Classification 🍕

## Overview
Transfer learning using pretrained ResNet50 on Food-101 dataset.

## Dataset
- Food-101
- 101 classes, 101,000 images

## Model
- Base: ResNet50 (pretrained ImageNet)
- Framework: TensorFlow/Keras
- Key concept: Skip connections (residual blocks)

## Results
- Train Accuracy: 1.77%
- Note: Low accuracy due to only 2 epochs — needs more training
